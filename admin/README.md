# טיוטת טופס ותשתית

`index.html` הוא אבטיפוס חזותי בלבד, ללא הזדהות, שמירה, העלאת קבצים או פרסום. אין להשתמש בו לאיסוף מידע אמיתי. הוא לא נכלל באתר הציבורי. מיגרציית PostgreSQL ההתחלתית נמצאת ב־`../migrations/001_reports.sql`.

כדי להשלים את המערכת נדרשים API מאומת, התאמת הרשאות לחשבונות המתנדבים והרכז, העלאת תמונות פרטית, שמירת טיוטות, בדיקת האישורים ושלב פרסום שמפיק דו״חות Pelican ומפעיל בנייה מחודשת. אין לאפשר גישת מסד או מפתח Render בדפדפן.
